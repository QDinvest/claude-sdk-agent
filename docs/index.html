The pain

Free credits you can't actually use

The grant has fine printPromotional credits list the products they cover. Mine covered the API and the Agent SDK. Claude Code wasn't on the list.
Claude Code bills elsewhereIt drew from my $2.85 of purchased credit and stopped with "not enough credit" while $200 in promo credit sat unused.
The API alone is just textA plain API chat can't open your repo, edit a file or run a test. You end up copying code by hand.
The fix

A coding agent on the Agent SDK, in three steps

One Python file. Works in any folder or repo, keeps a separate chat per folder, and prints what each message cost.

Install

Python 3.10+ · any OSgit clone https://github.com/QDinvest/claude-sdk-agent
python -m pip install -r claude-sdk-agent/requirements.txt

Set your API key

Windows PowerShell$env:ANTHROPIC_API_KEY = "your-key"
macOS / Linuxexport ANTHROPIC_API_KEY="your-key"

Start it in your repo

from inside the repo you want to work onpython path/to/claude-sdk-agent/skills/sdk-agent/scripts/agent.py

Add --model claude-opus-5-5 for Opus, --budget 5 to change the per-message cap, or --new for a fresh chat.

Before a long session

Check your own grant

Grants differ. Mine listed the Agent SDK, and a test run came out of the promotional balance. Check yours:
  1. Open the Console's Billing page and note both balances.
  2. Send the agent one short message.
  3. Refresh and see which balance dropped.
